# Living UI

Living UI is CraftBot's app-builder: describe an app in chat and the agent designs, codes, tests, and launches a full web application that runs locally, embedded in the CraftBot browser interface.

!!! warning "Section under construction"
    The Living UI system is being finalized and this section will be written once it lands.
    Until then, the fastest way to explore is to open the **Living UI** tab in the browser
    interface and create an app from the modal.
